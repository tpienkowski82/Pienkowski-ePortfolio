Artifact Description

The artifact is the CS-465 Travlr Getaways web application. It began as a Node.js and Express MVC project with routes, controllers, views, public assets, and travel page functionality.

Enhancement Summary

The software design and engineering enhancement improves the project by moving away from hardcoded or static presentation and toward a more dynamic JSON-based structure. This creates a clearer separation between data, controller logic, and view rendering.

The enhancement supports maintainability because trip information can be updated more easily without manually rewriting page content. It also improves the overall organization of the application and supports a more professional full-stack design.
