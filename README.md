# Tom Pienkowski CS 499 ePortfolio

This repository contains my CS 499 Computer Science ePortfolio. The ePortfolio showcases my growth throughout the Computer Science program through a code review, enhanced artifacts, written narratives, and a professional self-assessment.

## Artifact

The artifact used for this ePortfolio is the CS-465 Travlr Getaways project. This project began as a web application built with Node.js, Express, routes, controllers, views, static assets, and travel-related data. I selected this artifact because it allowed me to demonstrate growth in the three required computer science categories:

- Software design and engineering
- Algorithms and data structures
- Databases

## Code Review

The code review video explains the original functionality of the Travlr artifact, analyzes the existing code, identifies areas for improvement, and describes the planned enhancements.

## Enhancement One: Software Design and Engineering

For the software design and engineering enhancement, I improved the structure, organization, layout, and maintainability of the Travlr project. This enhancement focused on making the application more professional, easier to update, and clearer for users.

## Enhancement Two: Algorithms and Data Structures

For the algorithms and data structures enhancement, I improved how the application processes travel data. This included adding or improving search, sort, filter, and result-handling functionality so users can interact with trip information more effectively.

## Enhancement Three: Databases

For the database enhancement, I added a stronger database-style persistence layer, trip model validation, CRUD operations, and supporting API logic. This enhancement demonstrates safer and more reliable handling of travel records.

## Course Outcomes

This ePortfolio demonstrates progress toward the CS 499 course outcomes by showing my ability to design and evaluate computing solutions, communicate technical work clearly, apply algorithmic principles, use professional development tools, and consider security and data protection in software design.
