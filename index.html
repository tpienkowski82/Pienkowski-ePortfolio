Portfolio Overview

This ePortfolio presents my work from the CS-465 Travlr Getaways project as the central artifact for the CS 499 capstone. The project was selected because it provides a strong full-stack foundation and can demonstrate growth across the three required computer science categories.

The artifact begins as a travel website using an MVC structure and progresses through enhancements that improve design, introduce stronger data-processing logic, and add a database-focused persistence layer.
