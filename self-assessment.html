Assessment Overview

This self-assessment introduces the CS 499 ePortfolio and explains how the Travlr Getaways artifact demonstrates growth in software design and engineering, algorithms and data structures, databases, technical communication, and security-aware thinking.

The ePortfolio uses the CS-465 Travlr Getaways project as the central artifact. The artifact begins as an MVC travel web application and is enhanced across the three required capstone categories.

Skill Areas Demonstrated

  • Software design and engineering: Improved organization, maintainability, MVC structure, dynamic data handling, and user-facing design.
  • Algorithms and data structures: Added search, filter, sort, result count, and computed data logic to improve how trip information is processed.
  • Databases: Added persistence, model validation, CRUD operations, API routes, and supporting database tests.
  • Communication: Created a code review, portfolio pages, and narratives that explain technical decisions clearly.
  • Security mindset: Strengthened validation, error-aware design, and safer handling of data.
